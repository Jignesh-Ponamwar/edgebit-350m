# EdgeBit-350M Demos

Deployable demonstrations of EdgeBit-350M for practical tasks.

## Available Demos

| Demo | Description | Use Case |
|------|-------------|----------|
| [CLI Assistant](cli_assistant.py) | Interactive text generation | General edge assistant |
| [Ticket Classifier](ticket_classifier.py) | Support ticket routing | Customer service automation |
| [Summarizer](summarizer.py) | Short text summarization | Document processing |
| [RAG Demo](rag_demo.py) | Retrieval-augmented generation | Knowledge-grounded Q&A |
| [Edge Deploy](edge_deploy.py) | Minimal deployment example | Raspberry Pi / IoT |

## Setup

```bash
# From the project root:
pip install -r requirements.txt

# Run any demo (uses tiny model by default for quick testing):
python demos/cli_assistant.py --preset tiny

# With a trained checkpoint:
python demos/cli_assistant.py --checkpoint /path/to/checkpoint --config configs/model_350m.yaml

# Offline smoke checkpoint generated by the quick-start command:
python demos/edge_deploy.py --checkpoint smoke_output/pipeline_check/checkpoint-1 \
  --config configs/model_smoke.yaml --tokenizer simple
```

## Notes

- All demos default to the `tiny` preset (50M params) for quick testing without a trained checkpoint
- For production use, provide a trained checkpoint with `--checkpoint`
- `edge_deploy.py` supports `--tokenizer simple` for offline smoke checkpoints
- On Raspberry Pi, set `OMP_NUM_THREADS=4` for optimal performance
